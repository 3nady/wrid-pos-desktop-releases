## Install

1. Download and double-click `WridPos-0.2.0-x64.msi`.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway** (the file is not code-signed yet).
3. Click **Next**, **Install**, accept the administrator prompt, then **Finish**. The app installs to `C:\Program Files\Wrid POS` with a desktop shortcut.

Silent install for many PCs (administrator Command Prompt): `msiexec /i WridPos-0.2.0-x64.msi /qn`

A newer version installs over the old one and keeps the sign-in, settings and printers.
