## Install

1. Download and double-click `WridPos-0.2.6-x64.msi`.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway** (the file is not code-signed yet).
3. Click **Next** twice. On **Install options** choose "Create a desktop shortcut" (on by default) and "Start with Windows" (off by default), then **Next**, **Install**, and accept the administrator prompt.
4. Leave **Launch now** ticked and click **Finish**. The app installs to `C:\Program Files\Wrid POS`.

Silent install for many PCs (administrator Command Prompt): `msiexec /i WridPos-0.2.6-x64.msi /qn`. Add `DESKTOP_SHORTCUT=0` to skip the desktop shortcut or `START_WITH_WINDOWS=1` to start the app with Windows.

A newer version installs over the old one and keeps the sign-in, settings, printers and install options.
