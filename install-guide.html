1المتطلباتRequirements

  • جهاز يعمل بنظام Windows 10 أو Windows 11 بنسخة 64-بت.
  • صلاحية مسؤول (Administrator) على الجهاز مرة واحدة أثناء التثبيت.
  • مساحة فارغة 300 ميجابايت تقريباً.
  • اتصال بالإنترنت: البيع وفتح الوردية وإغلاقها تحتاج اتصالاً بالخادم.
  • رقم جوال وكلمة مرور لحساب وريد، ونقطة بيع (جهاز POS) معرّفة للشركة على الخادم.
  • لا حاجة لتثبيت .NET أو أي برنامج آخر: كل ما يلزم موجود داخل المثبّت.
  • A PC running Windows 10 or Windows 11, 64-bit.
  • Administrator rights on the PC, once, during installation.
  • About 300 MB of free disk space.
  • An internet connection: selling, opening and closing a shift need the server.
  • A Wrid account (mobile number and password) and a POS device set up for the company on the server.
  • No need to install .NET or anything else: the installer contains everything.

2الحصول على ملف التثبيتGet the installer

ملف التثبيت اسمه WridPos-0.1.2-x64.msi (حوالي 50 ميجابايت). احصل عليه بإحدى الطريقتين:

The installer is WridPos-0.1.2-x64.msi (about 50 MB). Get it one of two ways:

  1. رابط مباشر (الأسهل): تنزيل WridPos-0.1.2-x64.msi
    https://github.com/3nady/wrid-pos-desktop-releases/releases/download/v0.1.2/WridPos-0.1.2-x64.msi
    الرابط عام ولا يحتاج تسجيل دخول. صفحة الإصدار: v0.1.2
  2. نسخ مباشر: انسخ الملف بذاكرة USB من الجهاز الذي بُني عليه، من المجلد D:\Wrid System\WridPOS\desktop\artifacts\.
  1. Direct link (easiest): Download WridPos-0.1.2-x64.msi
    https://github.com/3nady/wrid-pos-desktop-releases/releases/download/v0.1.2/WridPos-0.1.2-x64.msi
    The link is public, no sign-in needed. Release page: v0.1.2
  2. Direct copy: copy the file on a USB stick from the PC it was built on, folder D:\Wrid System\WridPOS\desktop\artifacts\.

3التثبيتInstall

  1. انقر نقراً مزدوجاً على WridPos-0.1.2-x64.msi.
  2. إذا ظهرت نافذة «حمى Windows جهاز الكمبيوتر» (SmartScreen): اضغط «مزيد من المعلومات» ثم «تشغيل على أي حال». تظهر لأن الملف غير موقّع رقمياً بعد.
  3. في نافذة الترحيب اضغط Next. اترك مجلد التثبيت كما هو (C:\Program Files\Wrid POS) واضغط Next ثم Install.
  4. وافق على طلب صلاحية المسؤول (UAC) بالضغط على نعم.
  5. عند الانتهاء اضغط Finish. ستجد اختصار «وريد - Wrid POS» على سطح المكتب وفي قائمة ابدأ.
  1. Double-click WridPos-0.1.2-x64.msi.
  2. If "Windows protected your PC" (SmartScreen) appears: click More info, then Run anyway. It shows because the file is not code-signed yet.
  3. On the welcome page click Next. Keep the install folder (C:\Program Files\Wrid POS), click Next, then Install.
  4. Accept the administrator prompt (UAC) with Yes.
  5. Click Finish. A "وريد - Wrid POS" shortcut is on the desktop and in the Start menu.

تثبيت صامت (لعدة أجهزة)Silent install (many tills)

من نافذة «موجّه الأوامر» بصلاحية المسؤول، في مجلد الملف:

From an administrator Command Prompt, in the file's folder:

msiexec /i WridPos-0.1.2-x64.msi /qn

4أول تشغيلFirst run

  1. افتح «وريد - Wrid POS» من سطح المكتب. اللغة الافتراضية العربية، وزر English في شاشة الدخول يغيّرها فوراً.
  2. أدخل رقم الجوال بدون 966 وبدون الصفر (مثال 5XXXXXXXX) وكلمة المرور، ثم اضغط دخول.
  3. تفتح صفحة نقطة البيع. إذا لم تكن هناك وردية مفتوحة: اختر جهاز نقطة البيع، راجع رصيد الافتتاح، واضغط فتح الوردية.
  4. تظهر شاشة البيع: الأصناف على جهة والسلة على الجهة الأخرى. F2 للبحث، F7 لاختيار عميل، F9 للدفع.
  1. Open "وريد - Wrid POS" from the desktop. It starts in Arabic; the English button on the login screen switches at once.
  2. Enter the mobile number without 966 and without the leading zero (e.g. 5XXXXXXXX) and the password, then sign in.
  3. The POS page opens. With no open shift: pick the POS device, check the opening balance and open the shift.
  4. The till appears: products on one side, cart on the other. F2 search, F7 pick a client, F9 pay.
تبقى مسجّلاً
You stay signed in
الجلسة محفوظة ومشفّرة لمستخدم Windows الحالي، فلا يُطلب الدخول عند كل تشغيل. كل مستخدم Windows على الجهاز له جلسته وإعداداته. The session is saved, encrypted for the current Windows user, so you are not asked to sign in at every start. Each Windows user on the PC has their own session and settings.

  1. ثبّت تعريف الطابعة من الشركة المصنّعة أولاً (للطابعات المتصلة بـ USB)، وتأكد أنها تطبع صفحة تجريبية من Windows.
  2. في البرنامج افتح الإعدادات ← الطابعات.
  3. في «طابعة الفواتير (هذا الجهاز)» اختر طريقة الاتصال:
  1. Install the printer's driver from its maker first (for USB printers) and check that Windows prints a test page.
  2. In the app open Settings → Printers.
  3. Under "Receipt printer (this computer)" choose the Connection:

POS printers on the server

If the POS has network printers set up on the server, the app prints on them by default. To use this PC's printer, choose "Print receipts on: This computer's printer".

6ماسح الباركودBarcode scanner

أي ماسح USB يعمل كلوحة مفاتيح (وهو النوع الشائع) يعمل مباشرة بدون إعداد. صوّب على المنتج وشاشة البيع مفتوحة: يكتب الماسح الرمز في خانة البحث ويضغط Enter، فيُضاف المنتج للسلة. إذا لم يُضف، اضغط F2 ثم امسح مرة أخرى.

Any USB scanner that acts as a keyboard (the common kind) works with no setup. Scan with the till open: the scanner types the code into the search box and presses Enter, and the product goes into the cart. If not, press F2 and scan again.

7عنوان الخادمServer address

يتصل البرنامج افتراضياً بالخادم https://api.dev.wrid.sa. لا تغيّره إلا بطلب من الدعم الفني. طريقتان للتغيير:

By default the app connects to https://api.dev.wrid.sa. Change it only when support asks you to. Two ways:

  • لهذا المستخدم: الإعدادات ← عنوان الخادم ← حفظ. يُسجَّل خروجك بعد التغيير.
  • لكل مستخدمي الجهاز: افتح المفكرة كمسؤول، وعدّل الملف C:\Program Files\Wrid POS\appsettings.json. التحديثات اللاحقة تحافظ على هذا التعديل.
  • For this user: Settings → Server address → Save. You are signed out after the change.
  • For every user of the PC: open Notepad as administrator and edit C:\Program Files\Wrid POS\appsettings.json. Later updates keep the edit.
{
  "ApiUrl": "https://api.dev.wrid.sa"
}
تنبيه
Caution
الخادم api.dev.wrid.sa يعمل على قاعدة البيانات الحقيقية. كل بيع أو وردية أو ترتيب منتجات تجريبي يُسجَّل فعلاً لدى الشركة. جرّب بحساب شركة تجريبية. api.dev.wrid.sa runs on the real database. Every test sale, shift or product order is recorded for the company. Test with a test company account.

8التحديث والإزالةUpdate and remove

  • التحديث: شغّل ملف MSI للإصدار الأحدث بنفس الطريقة. يحلّ محل القديم مباشرة وتبقى الجلسة والإعدادات والطابعات كما هي. لا داعي لإزالة القديم أولاً.
  • الإزالة: الإعدادات ← التطبيقات ← «وريد - Wrid POS» ← إلغاء التثبيت.
  • بيانات المستخدم (الجلسة، الإعدادات، الطابعات، البيانات المحفوظة، السجلات) في %LOCALAPPDATA%\WridPos، ولا تُحذف عند الإزالة. احذف المجلد يدوياً لإزالتها بالكامل.
  • Update: run the newer version's MSI the same way. It replaces the old one in place; the session, settings and printers are kept. No need to uninstall first.
  • Remove: Settings → Apps → "وريد - Wrid POS" → Uninstall.
  • User data (session, settings, printers, saved data, logs) is in %LOCALAPPDATA%\WridPos and is not deleted on uninstall. Delete that folder by hand to remove it completely.
